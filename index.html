Passed, failed and broken come from the Allure report of each run. Known issues (blue) are tests marked "expected to fail" for confirmed app bugs, plus UI tests skipped because the site's bot protection (Cloudflare) blocks the browser on GitHub's runners (see the README; they pass locally). Broken means the test could not finish, for example when the shared site was slow or unreachable, rather than a failed check. The with-bugs environment is a copy of the shop with deliberate bugs, so failures there are expected.
